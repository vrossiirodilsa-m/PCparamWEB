# PCparamWEB
The phone displays information about the processor, RAM, graphics adapter, and network on the web page. In the browser, enter your PC’s IP address and the program’s port (you can change it). The phone and PC must be on the same local network.

PCparamWEB: Lightweight Windows Hardware Monitor Высокопроизводительный и легковесный монитор системных параметров для Windows, написанный на Go. Проект разработан как альтернатива громоздким программным комбайнам (AIDA64, LibreHardwareMonitor и др.) за счет отказа от тяжелых WMI/ACPI запросов в пользу прямого доступа к аппаратным регистрам процессора (MSR) на уровне ядра (Ring 0).
Архитектура и технические детали
Проект построен по модульному принципу: веб-интерфейс на Go общается с низкоуровневым хелпером, который через специальный мост взаимодействует с ядром операционной системы.
1. Взаимодействие Go с DLL (syscall & unsafe)Поскольку язык Go не имеет встроенных средств для прямого чтения регистров процессора в защищенном режиме Windows, утилита использует динамическую загрузку библиотеки через пакет syscall: Задействуется стандартный механизм ленивой загрузки (syscall.NewLazyDLL). Происходит инициализация через стандартизированную экспортируемую точку входа InitializeOls библиотеки OpenLibSys. Чтение регистров выполняется через функцию Rdmsr, передавая управление в драйвер ядра без накладных расходов.
2. Зачем нужен WinRing0? Современные версии Windows (x64) жестко блокируют прямой доступ к портам ввода-вывода и Model Specific Registers (MSR) из пользовательского пространства (Ring 3). Для обхода этой защиты используется связка компонентов WinRing0:WinRing0x64.sys — подписанный драйвер режима ядра (Ring 0), который выполняет физическое чтение MSR-регистров по запросу. WinRing0x64.dll — пользовательская библиотека-обертка, реализующая безопасный интерфейс передачи команд между Go-приложением и драйвером.
3. Чтение MSR и расчет температуры (Supports Intel processors (Xeon / Core), NO AMD) Температура процессора считывается напрямую из аппаратного регистра IA32_THERM_STATUS (адрес 0x19C). Алгоритм получения данных: Утилита вызывает функцию Rdmsr(0x19C, &eax, &edx). Из младшего регистра EAX извлекается значение цифрового датчика (Digital Readout), сдвигом вправо на 16 бит и маской 0x7F:$$\text{DigitalReadout} = (\text{EAX} \gg 16) \& \text{0x7F}$$Итоговая температура рассчитывается по официальной формуле для процессоров Intel Xeon:$$\text{CPU Temp} = 100.0 - \text{DigitalReadout}$$

Важное предупреждение (Disclaimer)
Требования к окружению:
Для работы модуля мониторинга железа (WinRing0) требуются права Администратора. Без них драйвер ядра не сможет инициализироваться, а системные вызовы MSR вернут ошибку доступа.
Убедитесь, что утилита и веб-сервер запускаются с соответствующими привилегиями.

🚀 Быстрый старт
Поместите исполняемые файлы (PCparamWEB.exe, temp_helper.exe) вместе с драйверами WinRing0x64.dll и WinRing0x64.sys в одну директорию. Они есть в архиве install.rar
Запустите приложение от имени Администратора.
Откройте в браузере http://localhost:8080 (или ваш настроенный порт).
